# ThiagoChat Open Source
Code source Turbowarp de :

- Thiago Torch Chat
- Thiago Torch Chat Lite
- Thiago Torch Chat Lite (Kahoot!)
- ~~ThiagoChat Next~~ _Indisponible car le fichier est trop gros_
- OpenCloudChat

## Ouvrir les fichiers
Ouvrez les fichiers au format SB3 avec [TurboWarp](https://turbowarp.org/editor) et les fichiers au format TORCH avec [CodeTorch](https://codetorch.net/fr/projects/editor).
Vous ne pouvez pas ouvrir ces fichiers avec Scratch.
