# ThiagoChat Open Source
Code source des applications web ThiagoChat : chats en "variable cloud" crées avec des logiciels de codages par blocs comme [Turbowarp](https://turbowarp.org/editor)

## Torch Chat/Torch Chat Lite
Des projets simple à modifier et à publier.

## OpenCloudChat
Un chat très minimaliste : c'est à vous de coder les fonctionnalités que vous souhaitez avoir.

## ThiagoChat Next
Ce projet s'adapte à la hauteur et la largeur de l'appareil, mais est plus complexe à modifier.
_Pas encore disponible en open source_

## Ouvrir les fichiers
Ouvrez les fichiers au format SB3 avec [TurboWarp](https://turbowarp.org/editor) et les fichiers au format TORCH avec [CodeTorch](https://codetorch.net/fr/projects/editor).
Vous ne pouvez pas ouvrir ces fichiers avec Scratch.
